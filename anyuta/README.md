# Портфолио — Анна Мирзоян

Сайт-портфолио графического дизайнера Анны Мирзоян.

## 🚀 Запуск локально

```bash
python -m http.server 8080
```
Затем открыть в браузере: [http://localhost:8080](http://localhost:8080)

## 📱 Адаптивность

- **Desktop** (> 900px) — полный вид с анимациями
- **Tablet** (≤ 900px) — адаптированная сетка, меньшие шрифты
- **Mobile** (≤ 600px) — вертикальная компоновка, вертикальный скролл

## ✨ Функционал

- Переключение вкладок: Главная / Обо мне / Проекты / Контакты
- Кастомный серебряный курсор с эффектами hover
- Анимации появления элементов
- Эффекты свечения при наведении
- Лайтбокс для просмотра фотографий работ:
  - Нажмите на фото для открытия
  - Нажмите снова (или `Esc`) для закрытия
  - Колесо мыши — приближение/отдаление
